# Version History

## [1.2.0] - 2026-11-25

SEO release based on the `seo-review` audit (see `docs/seo-audit-2026-11-25.md`
and `docs/seo-reaudit-2026-11-25.md`). Audit score: 184/330 → 288/330.

### Added

- Per-page metadata helper (`app/lib/seo.ts`): self-referencing canonical,
  Open Graph and Twitter tags on every page
- Structured data: `HairSalon` (LocalBusiness) on Home and Visit Us, `Service`
  and `BreadcrumbList` on service pages, `FAQPage` on the FAQ
- Service page content: question-and-answer section, what's included, steps,
  service FAQs, breadcrumb and related services (driven by `app/lib/services.ts`)
- Price table on the Services page and a downtown Akron visit section on Home
- Seven new FAQ questions (12 total) with links to the matching pages
- Franchise "how to open" section; gallery intro and captions linking to services
- Self-hosted Font Awesome subset generated by `scripts/icons.mjs`
  (`npm run icons`, runs automatically before `dev` and `build`)
- Shared site constants: `SITE_URL`, `BUSINESS_NAME`, `DIRECTIONS_URL`,
  `CLIENTS_SERVED`, `FACEBOOK_URL`, `GBP_URL`
- `seo-review` Claude skill in `.claude/skills/`

### Changed

- New titles and meta descriptions for every page
- Sitemap URLs now include the trailing slash
- Gallery images renamed to descriptive file names with accurate alt text
- One business name used across structured data, titles, footer and map
- Footer lists every page, links phone and email, and hides the Facebook icon
  until `FACEBOOK_URL` is set
- Client count unified to 5k+ on Our Story and Franchise
- Font Awesome no longer loads from the cdnjs CDN

### Fixed

- Service page canonicals pointed to a non-www URL two redirects away
- FAQ answers were missing from the server-rendered HTML
- Invalid `Barbershop` schema.org type in the homepage JSON-LD
- Footer column titles were invisible (heading color matched the background)
- Reviews page showed reviewer photos and initials the wrong way round
- Reviews meta description called every review "five-star"
